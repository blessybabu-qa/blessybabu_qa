## 🧠 Philosophy & Approach

- 🎯 **Test coverage as a feature** — Every test is traceable back to a real user scenario, not just a happy path.
- 🧩 **Modular by design** — Page objects, data layers, and reporting each live in their own domain.
- 🔍 **Manual roots, automation mindset** — My background means I catch edge cases pure automation engineers miss.
- ⚖️ **Right tool, right problem** — I evaluate context first: REST API, React SPA, or native mobile — then choose accordingly.
